## 🎓 Advanced Search Tips

### 1. Time-Sensitive Queries
Add temporal keywords for current information:
- "latest"
- "recent"
- "current"
- "today"
- "this week"
- "this year"

Example:
```
"Find the latest developments in AI"
"What are the current trends in cybersecurity?"
```

### 2. Comparison Queries
Use comparison keywords:
- "versus", "vs"
- "compare"
- "difference between"
- "better"

Example:
```
"Compare React vs Angular"
"Find the difference between Python and JavaScript"
```

### 3. Product Research
Include specific aspects:
- "reviews"
- "pricing"
- "features"
- "alternatives"

Example:
```
"Find reviews of MacBook Pro 2025"
"Search for alternatives to Photoshop"
```

### 4. Location-Specific Queries
Add location context:
- "in [location]"
- "near me"
- "local"

Example:
```
"Find restaurants in Tokyo"
"Search for tech companies in Silicon Valley"
```

## 🔧 Search Providers

The system supports multiple search providers:

1. **DuckDuckGo** (Default)
   - No API key required
   - Good for general searches
   - Privacy-focused results

2. **SerpAPI** (Premium)
   - Requires SERPAPI_API_KEY
   - Enhanced search capabilities
   - More structured results

3. **Google Custom Search**
   - Requires GOOGLE_API_KEY and GOOGLE_CSE_ID
   - Access to Google's search index
   - Customizable search parameters

## 💡 Best Practices

1. **Be Specific**
   - Instead of: "Python"
   - Better: "What is Python programming language used for?"

2. **Include Context**
   - Instead of: "machine learning"
   - Better: "Find recent applications of machine learning in healthcare"

3. **Use Time References**
   - Instead of: "AI news"
   - Better: "Find the latest news about AI breakthroughs"

4. **Specify Source Types**
   - "Find academic papers about X"
   - "Search for news articles about Y"
   - "Look up research studies on Z"

## 🚫 Common Mistakes to Avoid

1. **Too Vague**
   ❌ "technology"
   ✅ "Find information about emerging technologies in 2025"

2. **No Search Intent**
   ❌ "cars"
   ✅ "Search for electric car reviews 2025"

3. **Missing Context**
   ❌ "price"
   ✅ "What is the current price of Bitcoin?"

4. **Ambiguous Terms**
   ❌ "Java"
   ✅ "Tell me about Java programming language"
