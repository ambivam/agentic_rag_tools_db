# Calculator Examples

The calculator agent supports a wide range of mathematical operations, from basic arithmetic to advanced functions and unit conversions. Here are comprehensive examples in different categories:

## Basic Arithmetic
```
2 + 2
15 - 7
6 * 8
100 / 5
2 ** 3 (or 2^3)
(10 + 5) * 2
```

## Advanced Mathematical Functions
```
sqrt(16)
sin(45)
cos(60)
tan(30)
log(100)
ln(20)
exp(2)
abs(-15)
round(3.7)
ceil(4.3)
floor(4.8)
factorial(5)
```

## Unit Conversions

### Length Conversions
```
convert 10 meters to feet

### Weight/Mass Conversions
```
convert 100 kg to lbs

### Temperature Conversions
```
convert 32 F to C

```

### Volume Conversions
```
convert 1 gallon to liters
500 ml to cups

```

## Complex Calculations
```
(sqrt(25) + 10) * 2
sin(45) + cos(45)
log(100) / ln(10)
2 * pi * 5
abs(-10) + ceil(4.3)
```

## Using Mathematical Constants
```
pi * 5^2 (area of circle)
e^2
tau / 2
```

## Tips for Best Results
1. For basic arithmetic, use standard operators (+, -, *, /, **, ^)
2. For unit conversions, use either format:
   - "convert X units to units"
   - "X units to units"
3. For functions, use standard notation (sqrt, sin, cos, etc.)
4. Temperature units can be specified as:
   - C, Celsius
   - F, Fahrenheit
   - K, Kelvin
5. When using multiple operations, use parentheses to ensure correct order of operations

## Supported Units

### Length Units
- mm (millimeters)
- cm (centimeters)
- m (meters)

- in (inches)
- ft (feet)
- yd (yards)

### Weight Units
- mg (milligrams)

- kg (kilograms)

- oz (ounces)

### Volume Units
- ml (milliliters)

- gal (gallons)
- qt (quarts)

- cup (cups)
- fl_oz (fluid ounces)

## Error Handling
The calculator will provide clear error messages for:
- Invalid mathematical expressions
- Unsupported units or conversions
- Division by zero
- Invalid function arguments (e.g., sqrt of negative number)
- Syntax errors
